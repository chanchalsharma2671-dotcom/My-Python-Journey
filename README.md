# 🚀 My Python Journey

Welcome to my Python repository! This is a dedicated space where I document my learning progress, experiment with basic concepts, and build beginner-friendly Python scripts.

## 📁 Repository Structure

*   **01-Basic-Calculators:** Contains simple mathematical logic scripts.
    *   `Sum of two numbers.py` - Adds two user-input numbers.
    *   `Calcuator.py` - A simple command-line calculator.
    *   `Area of circle.py` - Calculates the area based on the given radius.
*   **02-Utility-Tools:** Handy tools for everyday problems.
    *   `Bill split project.py` - Easily splits restaurant bills among friends.
    *   `TEMPREATURE.py` - Converts temperature between Celsius and Fahrenheit.

## 🛠️ Tech Stack & Requirements

*   **Language:** Python 3.x
*   **Environment:** Terminal / Command Prompt

## 🏃 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory and run any script:
   ```bash
   python "Bill split project.py"
   ```
